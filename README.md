# Oasis Infobyte Android Development Internship Projects (OIBSIP)

This repository contains the complete set of Android applications developed during my **Android Development Internship at Oasis Infobyte (OIBSIP)**. All projects are built using **Java**, **XML**, and **Android Studio**, adhering to standard mobile application design principles, custom branding, and robust architecture.

---

## 📱 Repository Structure & Projects Overview

### 1. 📐 Task 1: Unit Converter App (`Android-Task1-UnitConverter`)
A versatile, intuitive unit conversion application designed for fast everyday calculations.
* **Key Features:** Real-time conversion across multiple measurement units (Length, Weight, Temperature, etc.), dynamic input processing, clean dark-themed UI.
* **Tech Stack:** Java, XML Layouts, Material Design Components.

---

### 2. ✅ Task 2: To-Do App (`Android-Task2-ToDoApp`)
A full-featured personal task management application with user authentication and database persistence.
* **Key Features:**
  * Custom User Registration & Login flow (Name, Email, Password).
  * SQLite database integration (`users` and `tasks` tables) for complete CRUD operations.
  * Task completion status toggle with visual strikethrough logic.
  * Custom branding assets, profile avatar, and dark mode UI.
* **Tech Stack:** Java, SQLite (`SQLiteOpenHelper`), XML, SharedPreferences.

---

### 3. 🧮 Task 3: Calculator App (`Android-Task3-Calculator`)
A sleek, responsive calculator app for standard arithmetic and operational logic.
* **Key Features:** Precise calculation algorithms, error handling (division by zero, invalid input sequences), custom branding logo, and responsive button grid layout.
* **Tech Stack:** Java, XML TableLayout/GridLayout.

---

### 4. 🧠 Task 4: Quiz App (`Android-Task4-QuizApp`)
An interactive quiz application featuring dynamic scoring and progression tracking.
* **Key Features:** Categorized questions, instant score calculation, visual feedback on correct/incorrect answers, and final summary display.
* **Tech Stack:** Java, Custom Models, XML.

---

## 🛠️ Tools & Technologies Used
* **IDE:** Android Studio
* **Languages:** Java, XML
* **Database:** SQLite
* **Version Control:** Git & GitHub
* **Design & Branding:** Custom Vectors, App Icons (`mipmap`/`drawable`), Material UI
